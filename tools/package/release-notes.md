## Install (Windows 10/11)

1. Download **Dwarven-Realms-Planner-…-win64-setup.exe** below and run it. Nothing else to download.
2. Windows may say "Windows protected your PC" (the app is not signed yet). Click **More info**, then **Run anyway**.
3. Open **Dwarven Realms Planner**. The first start takes about 5 minutes, once: the app guides you (find the game, read it once, extract the data).

From version 0.2.1 the app updates itself: when a new version is out, an **Update** button appears in the top bar. One click installs it and restarts the app. You will not need to download anything again.

**Already on an older test version (0.1.x, 0.2.0, or the zip)?** Run this setup once. It replaces the old copy, and your data (game data, history, builds) is kept: no new extraction.

The planner contains no game data. It reads the data from your own installation of Dwarven Realms.
